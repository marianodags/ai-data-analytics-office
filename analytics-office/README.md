# Analytics Office extension (in development)

Local-first analytics-agent workflow and Habblaud visualization for five roles:

- Researcher
- Data Engineer
- Statistical Analyst
- Quality Assurance
- Reporting Specialist

**Current status:** design documents, agent configuration example, and an event schema only. The upstream Habblaud application is unchanged; it does not yet execute Ollama agents or consume n8n events.

Start with [Setup](../docs/analytics-office/SETUP.md) and [Architecture](../docs/analytics-office/ARCHITECTURE.md).

The event adapter, n8n workflow, and Python analytics API are planned additions. Do not interpret example configuration as running infrastructure.
